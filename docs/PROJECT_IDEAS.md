# プロジェクト案

StopWatch は「腕時計完成品」というより、丸形 AMOLED、触覚、音声、モーション、無線、拡張端子が小さな筐体に入ったインタラクション開発機です。最初は内蔵機能だけで完成する小さな作品から始め、必要なセンサーだけ外付けするのが扱いやすいです。

## 最初に作る 3 段階

### 1. Hardware Census

`00_smoke` から各診断環境を順に書き込み、次を記録します。

- Display / touch / Button A / B
- BMI270 の静止値と軸方向
- RTC の保持とバッテリー状態
- マイク録音、スピーカー再生、振動
- Wi-Fi scan と Bluetooth LE advertising
- Port A I2C scan
- 画面輝度別、Wi-Fi 使用時、sleep 時の電池減少

これは後の作品すべての基準になります。

### 2. Daily StopWatch

`99_stopwatch` を日常で使える最小版へ育てます。

- タップ / Button A: start・pause
- Button B: lap
- 長押し: reset
- RTC 時刻と経過時間を分離
- 操作ごとの短い振動
- 画面消灯中もタイマー状態を保持
- ラップ履歴の保存と USB シリアル出力

### 3. Networked Object

次に一つだけ外部接続を追加します。

- Wi-Fi: ブラウザからラベルやタイマーを設定
- BLE: スマホ / PC から start・stop、イベント通知
- Port A: 外部センサー値を丸形 UI に表示

## 内蔵ハードウェアだけで作れる案

| アイデア | 主な機能 | 難易度 | 面白さ / 注意点 |
| --- | --- | ---: | --- |
| ラップタイマー | タッチ、ボタン、RTC、振動 | 低 | 実用品。状態機械と省電力の基礎になる |
| ポモドーロ | RTC、画面、振動、スピーカー | 低 | 画面消灯と通知設計を試せる |
| ジェスチャータイマー | BMI270、振動 | 中 | 腕を返す、机に置く動作で start / stop |
| デジタルバッジ | AMOLED、Wi-Fi AP | 中 | ブラウザから画像や名前を送る。工場デモにも類似機能あり |
| BLE プレゼンリモコン | BLE GATT、ボタン、振動 | 中 | PC 側アプリとの往復確認。HID 化は別途設計 |
| 近接インタラクション | BLE advertising / RSSI | 中 | 個体間の距離は概算。作品的な揺らぎとして扱える |
| 声の断片採集器 | マイク、Flash、Wi-Fi | 中〜高 | 録音→停止→送信 / 再生の半二重設計 |
| 音に反応する文字盤 | マイク、AMOLED | 中 | 音量・周波数を視覚化。生音声を保存しない privacy mode も可能 |
| Motion Canvas | BMI270、AMOLED | 中 | 傾きで粒子や線を動かす。磁北は取れない |
| IoT 状態表示器 | Wi-Fi、AMOLED | 中 | 展示、サーバー、家庭機器の状態を一目で表示 |
| NTP 時計 | Wi-Fi、RTC | 低 | UTC、ローカル時刻、RTC 保持の設計練習 |
| 呼吸ペーサー | AMOLED、振動 | 低 | 円の明滅と触覚だけで静かなテンポを作る。医療用途ではない |

## 外付けセンサーで広がる案

Port A は G10 / G11 の I2C と 5 V 電源を提供します。センサーの信号電圧と pull-up が 3.3 V 系に適合することを確認してください。

| 外付け要素 | 作れるもの | 注意 |
| --- | --- | --- |
| 温湿度・気圧 | 環境文字盤、展示空間ロガー | センサーは内蔵ではない |
| GNSS | 移動軌跡、屋外タイマー | アンテナ、消費電力、屋内測位不可を考慮 |
| 心拍 / SpO2 | バイオフィードバック作品 | 医療機器ではない。皮膚接触、安全、較正、個人情報に注意 |
| 照度・近接 | 自動輝度、装着検出 | 外乱光や筐体配置を実測 |
| ToF 距離 | ジェスチャー UI、展示物との距離反応 | 視野角と反射率の影響あり |
| NFC / RFID | 物体・場所とのタッチ連携 | StopWatch 自体には NFC / RFID が内蔵されていない |

## 展示・研究向けの方向

### Tangible Timeline

物理ボタンで「いま」を刻み、ラップを丸い画面上の同心円として残します。Wi-Fi で複数台のラップを同期すれば、人ごとの時間感覚を空間に可視化できます。

### Haptic Score

BLE や Wi-Fi で短い振動譜を配信し、画面を見なくても参加者へ合図を送ります。振動の強さ、間隔、反復だけで情報をどこまで伝えられるかを検証できます。

### Motion Relic

BMI270 で「持ち上げられた」「伏せられた」「静止している」を検出し、その履歴を画面の痕跡として育てます。絶対方位ではなく、動きと静止の時間を素材にします。

### Whisper Relay

一台で短く録音し、停止後に Wi-Fi で次の端末へ送り、受信側が再生します。マイクとスピーカーの半二重制約を、作品の「聞く / 話すが交互に訪れる」ルールへ変換できます。

## 優先順位

1. 工場 Flash のバックアップと hardware census
2. `99_stopwatch` の日常利用テスト
3. deep sleep / 画面消灯を含む電池実測
4. BLE GATT リモコン
5. Wi-Fi 設定 UI と OTA の設計
6. 外部 I2C センサーを一種類だけ追加

OTA は便利ですが、最初から唯一の復旧経路にしません。USB ダウンロードモードと工場ファーム復元を常に残します。

## データと安全

- マイク音声、周囲の Wi-Fi SSID、BLE 識別子は個人情報になり得る。
- 音声やセンサーを取得するときは、記録中であることを画面で示す。
- 認証情報を Git へ入れない。
- 心拍・SpO2 などを外付けしても、健康判断や医療用途をうたわない。
- 防水仕様は確認されていないため、身体装着時も水分から保護する。
